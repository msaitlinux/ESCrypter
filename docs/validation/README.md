# Historical validation

`ubuntu-24.04-2026-10-24/` contains the recorded 0.2.0 development-candidate
checks from Ubuntu 24.04 amd64, before this GitHub preparation. These are not
GitHub CI results or Debian 13 certification. New runs write `test-results/`.
The package checksums refer to the historical split packages, not a new combined
package. Unix-socket tests were unavailable in that environment (exit 77).
